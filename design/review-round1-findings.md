# Round 1 findings (verbatim summaries from the three reviewers)

## Player

P1 must-fix: Tank touch stick does three jobs (up = rise AND swim, down = dive AND brake). Use camera-relative movement: stick moves forward/back/turn relative to camera; fish pitches toward where the camera looks (right-half drag aims); optional small rise/dive buttons above the action button; brake on release.
P2 should-fix: Desktop pointer-offset steering spins the fish whenever the mouse is off centre (e.g. reaching for HUD buttons). Steer from pointer only while left button held, or pointer lock with mouse-delta; no steering while over HUD.
P3 should-fix: Hits cost almost nothing (bites land in a ring around you, 2 s invulnerability covers the 3 s regrab). Scatter bites 2-3 cells along corridors, only ~half recoverable, 0.4 s daze, and a "clean run" reward (second star for clearing without a hit).
P4 should-fix: 0.35 s turn buffer drops early swipes (worse in 1.8x currents). Hold the buffered direction until taken, replaced, or 2 junctions passed; show a queued-turn arrow; swipe threshold ~24 px.
P5 should-fix: 15x9-cell camera on 25x15 mazes + darkness → hits from unseen enemies. Enemy glow through darkness, off-screen edge pips, 0.3 s shrimp tell before dart; consider a corner minimap.
P6 should-fix: Endgame grind: last Neon lady needs N+M = 620 bites after nesting. Cap N+M for the last ladies or speed up when everything else is nested, or a late "feeding frenzy" maze; simulate the whole run; no reward gap longer than ~2 mazes.
P7 should-fix: No notification when fry hatch/grow while away. Toast + chime ("Ruby's fry hatched!", "X is grown! Become him from the Map"), badge on the Map button.
P8 should-fix: Exit signs don't show nest cost/affordability → wasted trips. Labels show cost and whether you can pay; heart greyed until affordable; same on Map nodes.
P9 nice: Empty tanks and new fish change nothing you feel. Each fish gets a name, one-line personality, own munch pitch or bubble-trail colour; claimed empty tanks add to feeders or let you place a collected fish there.
P10 nice: Generator mazes may feel samey. Each maze gets a hand-placed signature feature and a name; introduce each world's mechanic gradually, one per maze, before combining.

## Builder

B1 must-fix: Recolour shader has no body/fin mask and UV-space patterns tear at seams. Bake geometry to model space; per-vertex aFin (distance outside a fitted body ellipsoid), aAlong (head→tail), height attributes; all patterns procedural in model space; Meshy texture used only as luminance detail; flare as vertex push by aFin; translucency by splitting fin triangles into a second double-sided transparent mesh (or opaque fins with fresnel edge). Concept pictures: clearly separated spread fins, pure side view. Prototype halfmoon first.
B2 must-fix: The world graph isn't in the design: which exit links to what, tank depth order, Grand Tank, arrival tanks, machines; what a lady tank does after its fry is become; how to return from World 3. Add per-world node/edge tables.
B3 must-fix: Maze spec contradicts itself: mirrored vs asymmetric exits; W1 wraps use side borders; two-char tile codes; 2x2 open blocks draw tube lattices; valves/currents not handled by BFS. Single-char tiles (1-4 exits, a/b portals, S start) + side table; mirror walls then carve exits; ban 2x2 open blocks; currents as directed weighted edges, valves always eventually passable; portal pairs reachable both sides; generator writes exit-to-exit shortest paths.
B4 should-fix: Movement rules missing: valve closing on an occupant; enemies and portals/wraps/currents; shrimp line of sight; arrival next to an enemy; 1.8x current vs cornering window; step() at 1/30 vs loop 1/60. Valve blocks entering only; enemies use wraps/currents not portals; crayfish treats closed valves as walls; shrimp sight raycast stops at walls/closed valves; 1.5 s arrival safety and enemies spawn ≥6 cells from exits; movement in cell-fraction space, step() uses same 1/60 update.
B5 must-fix: Phone load size: 14 GLBs ≈ 50-70 MB before title. Set --polycount (fish ~6k, props 3-5k, enemies ~4k) and --max-texture 512 for props/enemies; record sizes; boot loads fish + World 1 + room only (target < 20 MB), stream W2/W3 behind world card; instance fry; draw-call target < 150 per mode, check renderer.info.
B6 must-fix: "Crossed between every pair of exits (recorded solutions)" doesn't scale (60-80 pairs) and a real-input full run needs ~2,400 bites. Define __game.solve() as an autopilot feeding directions through the real input layer along precomputed BFS paths; iterate every exit pair automatically; hooks setTank, unlockDock, teleport, graph(); end-to-end run on ?fast=1 (all Z/N/M = 1) with real input, plus one real-number run through World 1.
B7 should-fix: Transparent instanced tubes will blotch at joints and hide things. Explicit draw order: backdrop → opaque dark corridor back-wall strip → fish/bites/enemies → fresnel shells depthWrite:false additive. Or merge tube geometry. W3: neon rims always visible, only interior dims.
B8 should-fix: Mode switches: shader compile hitches (keep patterns as uniforms: one program for all fish; renderer.compile per mode during loading); dispose maze groups on exit; clear held input & dir buffer on mode change, ignore input during wipe; save only in stable states; clamp tank camera inside water box, lower near surface.
B9 should-fix: Save format: stable string IDs per node (cw-lady-3); save shape {v, bites, eaten, fish, at, tanks:{id:{claimed, stage, laidAt, hatchedAt, grownAt, becameFish}}, fishHome, docks, stars, settings}; write on stable events plus 5 s debounce; migrations.
B10 nice: Touch zones (stick zone bottom-left 160 px stick only; swipes elsewhere, 24 px threshold; button zones excluded); preventDefault contextmenu; pipe mouse heading via raycast onto maze plane, dominant axis in grid space with hysteresis.

## Art and sound director

A1 must-fix: Betta fins, gill flare and translucent fins can't come from one Meshy model (Meshy fuses thin membranes, one surface). Make Meshy produce the BODY only (short-finned plakat-like platinum body with small fin stubs); build dorsal, anal, caudal, pectoral (and ventral) fins in code as curved double-sided ribbon meshes that flutter in a shader, textured with fin images made by imagegen2 on transparent background using the anchor as reference (halfmoon, crowntail rays, double-tail, plakat, female fins); gill flare as small code gill-cover + beard meshes swinging about a pivot. Fewer Meshy shapes; fin shape becomes data. Prototype halfmoon first; check from side and from pipe camera.
A2 must-fix: Recolour shader can't tell body/fins/eyes apart. Concept edit paints near-white body, flat key colour on fins (if on model), black eyes; at load make a mask; keep luminance as detail; leave dark pixels (eyes) untouched; patterns procedural in model space; 20 varieties' parameters in data/fish.js.
A3 should-fix: Pipe view: left/right = yaw (not roll, no belly-up); up/down pitch ~70° with dorsal toward camera up; fish scaled ~0.85 in pipes and flare capped inside tube (radius 0.55); show ~12x7 cells on coarse pointers; enemies get emissive eyes/rims to glow in W3; shared tint uniform for frightened/hit/returning.
A4 should-fix: Many on-screen objects missing from asset list: bites, brine shrimp, nest foam, eggs, fry, nest leaf, feeder, filter + bubble stream, tank glass/lid, ribbon, hanging tube, valve gate, current stripes, portal rings, wrap mouths, exit sign holders, player bubble, room shelves/tanks/lamp/window/padlock, Grand Tank. Add a code-built block with shape, colour, material, motion each.
A5 should-fix: Missing sounds: shrimp dart chirp, jelly pulse thrum, crayfish click, cat ear flick, courtship shimmer, valve clunk, deny boop, star ding, fry-news chime, fast travel, wrap, world card, room ambience loop, pipe ambience. ~+10 sfx (~$1.50).
A6 should-fix: Text-only Meshy enemies/props will drift from toy style. imagegen2 concept pictures (anchor as reference) for snail, shrimp, cat; text prompts only for small tank props, with --texture-prompt style words; state --height for every model.
A7 should-fix: Tube rendering & three world materials undefined; overlap blotches. depthWrite off, additive fresnel rims; opaque darker back-wall strip behind each corridor; Clearwater mint rim #bff3ea + caustic scroll; Copperworks opaque copper collars at joints over warm glass rim; Neon emissive magenta/cyan rims on navy back wall.
A8 should-fix: Download size; --max-texture 512 for enemies/props; load home-tank needs at boot, stream world backdrops/enemies/music behind title card; size target < 20 MB at boot.
A9 nice: Pipe music: 120 s tracks with resolving ending, 1.5 s crossfade at loop; optional second variation per world. Backdrops: far slow-parallax plane ≥1.4x the view, generate at 21:9.
